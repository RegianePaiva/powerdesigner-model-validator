## 🎯 Casos de uso

- **Governança de dados:** garantir aderência a padrões corporativos de modelagem
- **Qualidade de dados:** identificar não conformidades antes da implementação
- **Documentação:** assegurar completude de comentários em tabelas e colunas
- **Integridade referencial:** validar chaves primárias, estrangeiras e referências
- **Padronização:** aplicar nomenclatura consistente em todo o modelo
- **Auditoria:** gerar relatórios de conformidade para revisão

Os scripts deste repositório são **genéricos** e **não contêm dados, estruturas ou regras de negócio de qualquer organização específica**. Foram desenvolvidos a partir de experiência profissional em projetos de grande porte (órgãos públicos e instituição financeira) e adaptados para uso público.
