# Scripts

Esta pasta contém os scripts de validação de modelo físico no PowerDesigner.

## Scripts disponíveis

| Script | Descrição |
|---|---|
| `01_validar_nomenclatura.pws` | Valida padrões de nomenclatura |
| `02_validar_tipos_dados.pws` | Valida tipos e tamanhos de dados |
| `03_validar_comentarios.pws` | Valida completude de comentários |
| `04_validar_chaves_referencias.pws` | Valida chaves e integridade referencial |
| `05_validar_indices.pws` | Valida índices e constraints |
| `06_validar_obrigatoriedade.pws` | Valida campos obrigatórios |
